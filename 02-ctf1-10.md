1. cara melihat file tersembunyi
`ls -a` menampilkan file berawalan .
`ls -la` menampilkan semua file secara lengkap

2. cara pake find
`find / -user bandit7 -group bandit6 -size 33c 2>/dev/null`

3. cara satu-satunya baris teks yang tidak berulang hanya muncul 1 kali (level 8)
`sort data.txt | uniq -u`

4. mencari stings di file biner.txt
`strings data.txt | grep "="`

5. decode base64 -> teks
`base64 -d data.txt`	

6. Rot13 merotasi huruf sebanyak 13 langkah A=N
`cat data.txt | tr "A-Za-z" "N-ZA-Mn-za-m"`
